# Invix | AI-Powered Invoicing Platform

Invix is a premium, AI-driven invoicing and organizational management platform. It automates complex workflows such as invoice creation, legal document generation, and client risk assessment, allowing businesses and freelancers to focus on growth rather than paperwork.

## 🚀 Key Features

- **Voice to Invoice**: Generate professional invoices instantly using voice-to-text AI.
- **Legal Document Generation**: Effortlessly create MSAs, NDAs, and other essential legal agreements.
- **Client Risk Analysis**: Leverage intelligent data processing to assess client profiles and financial history.
- **Inventory Management**: Real-time stock tracking synchronized with your billing cycles.
- **Multi-Role Organization**: Structured company management with Admin, Manager, and User roles.
- **Personal Organizations**: Manage multiple independent businesses and workflows under a single account.
- **Smart Tracking**: Automated follow-ups and real-time status tracking for all invoices.
- **Premium UI**: Modern, responsive design built with a focus on aesthetics and user experience.

## 🛠️ Technology Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS 4.0](https://tailwindcss.com/)
- **Components**: [Shadcn UI](https://ui.shadcn.com/) (using [Base UI](https://base-ui.com/))
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🏁 Getting Started

### Prerequisites

- Node.js 18.0 or later
- npm (or pnpm / yarn)

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd InvixInfo
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.
